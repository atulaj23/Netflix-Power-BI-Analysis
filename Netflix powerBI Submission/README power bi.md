# Netflix Content Analysis

## About the Project

This project was created as part of my Power BI internship tasks at Auspify Technologies. I used a Netflix titles dataset to practise data cleaning, dashboard design, and analysing content trends.

## What I Worked On

- Cleaned and prepared the dataset for reporting.
- Built an overview dashboard with key counts for titles, movies, and TV shows.
- Explored country-level content distribution and added a map visual.
- Created charts to review content by release year and Netflix addition date.
- Compared content types, ratings, and catalogue categories.

## Tools Used

- Microsoft Power BI
- Power Query
- Netflix titles dataset (CSV)

## Report Pages

1. **Netflix Content Analytics** — overview of the catalogue and key metrics.
2. **Global Content Insights** — country distribution, map, and content trends.
3. **Content Growth & Trends** — release-year and content-added trends.
4. **Audience & Content Category Insights** — content ratings, types, and category combinations.

## Notes

The dataset contains catalogue information, not actual viewing figures or audience demographics. Country and genre fields can contain multiple values in a single row, so some visuals represent combined labels rather than fully separated country or genre counts.

## How to View

Open `Netflix_Content_Analysis.pbix` in Microsoft Power BI Desktop to explore the report pages and interact with the visuals.
